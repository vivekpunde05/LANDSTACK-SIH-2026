## Capture quality checklist

- Use synthetic/demo records only.
- Keep the LANDSTACK identity, fallback state, and human-review wording visible where relevant.
- Avoid browser developer tools, notifications, unrelated tabs, and local filesystem paths.
- Confirm no undefined values, error banners, broken tiles, or clipped controls appear.
- Prefer PNG and review file size before adding an image to Git.
- Do not add duplicate or low-quality captures merely to fill the directory.
